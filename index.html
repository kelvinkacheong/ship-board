Edit Mode Setup

To edit tasks, you need a GitHub Personal Access Token.
  1. Go to GitHub Fine-grained Tokens
  2. Click "Generate new token"
  3. Name it (e.g. "Ship Board Editor")
  4. Set repository access to "Only select repositories" → select kelvinkacheong/ship-board
  5. Under Permissions → Repository permissions → Contents: select Read and write
  6. Generate and copy the token

Your token is stored only in your browser's localStorage and never sent anywhere except GitHub's API.
